## 🏛️ Arsitektur Sistem & Aliran Data

Aplikasi menerapkan arsitektur **Clean Architecture (Layered Service-Oriented)** dengan model data hibrida **Local-First SQLite + Cloud Firebase Sync**:

```mermaid
flowchart TB
    subgraph ClientLayer ["📱 Frontend Layer (Flutter 3.47 Mobile & Tablet)"]
        UI_Pages["UI Pages & Views\n(Auth, Dashboard, Katalog, Pembayaran, Profil, Admin)"]
        UI_Widgets["Shared Reusable Widgets\n(Custom Modals, Input Forms, Cards)"]
        UI_State["State Management\n(CartService, BalanceService, ThemeService)"]
        UI_Pages --> UI_State
        UI_Widgets --> UI_Pages
    end

    subgraph ServiceLayer ["⚙️ Service & Logic Layer (lib/services)"]
        AuthSvc["Auth & Security Services\n(Google Sign-In, GitHub OAuth, Biometrik)"]
        SyncSvc["FirebaseTransactionService & RealtimeListener\n(Two-Way Sync Orchestrator)"]
        AISvc["AIChatService\n(Google Gemini Flash Model)"]
        PaymentSvc["MidtransDirectPaymentService\n(Automated QRIS & VA Bank Gateway)"]
    end

    subgraph StorageLayer ["🗄️ Hybrid Data Layer"]
        DBHelper["SQLite Helper (sqflite)\nFile: vibetech.db (8 Tabel Relasional)"]
        SharedPref["SharedPreferences\n(Sesi Token, Theme Dark/Light, SMTP Cache)"]
    end

    subgraph CloudLayer ["☁️ Cloud & External Gateway Backend"]
        FirebaseCloud["Firebase Multi-Platform\n(Auth, Cloud Firestore & Realtime Database)"]
        MidtransAPI["Midtrans Gateway\n(QRIS, GoPay, VA BCA/BRI/BNI/Mandiri)"]
        GoogleGemini["Google Gemini AI REST API"]
    end

    UI_State --> ServiceLayer
    ServiceLayer --> StorageLayer
    SyncSvc <--> DBHelper
    SyncSvc <--> FirebaseCloud
    AuthSvc <--> FirebaseCloud
    PaymentSvc <--> MidtransAPI
    AISvc --> GoogleGemini
```

## 🚀 Panduan Instalasi & Menjalankan

### 1. Prasyarat Sistem
* **Flutter SDK**: Versi `>= 3.0.0` (Direkomendasikan Flutter 3.47.x)
* **Dart SDK**: Versi `>= 3.0.0`
* **Node.js**: Versi `>= 18.x` & npm

### 2. Pemasangan Dependensi
```bash
# 1. Clone repositori
git clone -b firebase https://github.com/RazikSz/vibetech.git
cd vibetech

# 2. Pasang dependensi pustaka Flutter
flutter pub get

# 3. Pasang dependensi backend Node.js
cd backend
npm install
cd ..
```

### 3. Menjalankan Aplikasi
```bash
# Jalankan pada Android Device / Emulator
flutter run

# Jalankan pada Desktop Windows (Mendukung Sqflite FFI)
flutter run -d windows

# Jalankan pada Browser Chrome
flutter run -d chrome
```

### 4. Membangun Rilis Google Play Store (Android App Bundle)
```bash
flutter build appbundle --release
```
> Output file: `build/app/outputs/bundle/release/app-release.aab`
