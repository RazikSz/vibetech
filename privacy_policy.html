2. DATA PRIBADI YANG KAMI KUMPULKAN

Aplikasi VibeTech XYZ mengumpulkan beberapa kategori data pribadi yang diperlukan untuk kelancaran transaksi dan operasional infrastruktur:

A. Data Identitas Akun Pengguna

  • Data Pokok: Nama lengkap, alamat email aktif, username unik, dan nomor telepon/WhatsApp.
  • Data Profil: Foto avatar profil, lokasi tempat tinggal/kota, biografi akun, serta kode referral.
  • Peran Akun (Role): Hak akses akun sistem (user atau admin).

B. Data Keamanan & Kredensial Akun

  • Kata Sandi (Password): Disimpan dalam bentuk hash kriptografi terenkripsi dan tidak dapat dibaca langsung oleh siapapun.
  • PIN Transaksi 6-Digit: Digunakan untuk otorisasi checkout pembelian server, transfer saldo, dan perubahan konfigurasi akun.
  • Two-Factor Authentication (2FA): Status proteksi autentikasi ganda akun.
  • Log Riwayat Masuk (Login History): Catatan waktu login, provider (Email, Google Sign-In, GitHub OAuth), dan status autentikasi.
  • Data Biometrik (Sidik Jari / Face ID): Diproses 100% secara lokal melalui modul perangkat keras keamanan (Secure Enclave / Keystore) di perangkat Anda. VibeTech XYZ TIDAK PERNAH mengumpulkan, mentransmisikan, atau menyimpan data biometrik mentah Anda di server kami.

C. Data Transaksi Keuangan & VibeWallet

  • Nomor Invoice digital dan ID Pesanan (Order ID).
  • Paket layanan yang dibeli, kuantitas, total harga (Rupiah), catatan pesanan, dan tanggal transaksi.
  • Metode pembayaran yang digunakan (Saldo internal VibeWallet, QRIS Instant, Virtual Account Bank BCA/Mandiri/BRI/BNI/Permata, atau E-Wallet GoPay/DANA/OVO/ShopeePay).
  • Saldo aktif dan riwayat mutasi transaksi VibeWallet.

D. Data Layanan Server & Bot WhatsApp Aktif

  • Alokasi alamat IP server, port jaringan, URL panel server, dan username server VPS/Panel.
  • Session ID dan nomor sesi bot WhatsApp aktif.
  • Siklus aktif paket langganan dan tanggal kadaluarsa (expired date).

E. Data Interaksi Asisten Cerdas (Furina AI)

  • Pesan konsultasi dan prompt pertanyaan teknis mengenai spesifikasi server.
  • ID Sesi percakapan (Session ID) yang dapat direset atau dibersihkan kapan saja oleh pengguna melalui fitur Reset Session.

F. Data Tiket Bantuan & Notifikasi

  • Nomor tiket bantuan, nama pengirim, subjek kendala, rincian pesan bantuan, dan status penyelesaian tiket.
  • Riwayat pesan email transaksional dan kode OTP verifikasi pemulihan kata sandi.
